## Acceptance vs the director's directives

- **D1 — Soak is the single win condition: MET.** `match.js _hit` now accumulates `soak` 0→100 and emits `down` at `soak >= 100`; `hp` is derived as `100 - soak`. A grep for raw `hp +/-=` across `experiences/little-planet/src/` returns **clean** — no code path subtracts raw HP anymore. Soak resets on round start and next round. ✅
- **D2 — Saber melee identity: MET.** `leafblade.soak` is 100→**34** (≥3 clean hits to down); a swing spends `stamina` (0.34) and is blocked with a "Winded" tell when empty; an early-swing connect (`saber.swing <= 0.45`) deals 1.5×; a whiff past 0.7 shows "Exposed!". One caveat: the `_recoveryUntil` opening is **visual only** (not mechanically enforced) — the engineer flagged this as a deliberate follow-up. ✅ (with caveat)
- **D3 — Bots use the player kit: MET (balance caveat).** `botShoot` now fires `TOOLS` leafblade/petalbow with the player's soak numbers; the legacy hitscan `WEAPON`/`applySpread`/`traceShot` carbine is gone from the bot path. ✅ (see medium note below)

## Issues found

**🔶 MEDIUM — Bots now hit 100% of the time (balance drift).** `botbrain.js botShoot` applies full `stats.soak` on any LOS-valid frame with **no spread and no miss check**. The old code used `traceShot`+spread and dealt `WEAPON.damage*0.8`, so bots could miss and dealt less. Now a bot never whiffs, and damage is multiplied by `bot.rarityMult` (defaults to 1, but if bots are ever assigned rarity a legendary petalbow bot lands ~72 soak/shot). This inverts the old "deliberately worse than a human" intent. *Fix:* keep a skill gate (re-run a traceShot-style hit test, or add a miss/spread chance) and/or cap bot `rarityMult` for tactical.

**🔶 MEDIUM — Heal/soak desync (pre-existing, not from this PR).** Heals adjust the client's `hp`+`soak` locally, but the sim only ever *raises* soak on damage and never *lowers* it on heal. The next `damage` event recomputes `hp = 100 - soak` and snaps the healed bar back, so a heal item is effectively cancelled for a damaged player. Predates D1–D3. *Fix:* make heal authoritative in the sim (`target.soak = max(0, target.soak - heal)`).

**🟢 LOW — Bot ranged range mismatch.** `stats.range ?? 120` — soak tools have no `range` field, so bots apply soak out to 120m regardless of the projectile's real travel/gravity. *Fix:* add an explicit `range` per tool or clamp to effective range.

**🟢 LOW — `_recoveryUntil` is dead.** Set on "Exposed!" but never read; the whiff punish is a tell only. *Fix:* wire a real lock or drop the var (engineer already flagged).

**🟢 LOW — `this.soak` not initialized in the constructor.** Set lazily on damage/heal/down; harmless because the HUD derives soak from `100 - this.hp`, but fragile. *Fix:* `this.soak = 0` in the constructor.
