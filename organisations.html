Warum dafür zahlen, wenn öffentliche Daten frei sind?

Weil die teure Arbeit nicht das Herunterladen eines Gesetzes ist. Die teure Arbeit ist: hundert Quellen beobachten → Änderung erkennen → Relevanz filtern → Betroffene bestimmen → Quelle prüfen → nächsten Schritt vorbereiten → in das eigene System bringen → nichts Kritisches verpassen.
