# Citizen Agents — Verification

## Evidence today
- working public prototype;
- cited watchdog findings and structured logs;
- Civic Intelligence and Democracy Radar APIs;
- usefulness feedback model and evidence report;
- alerts/reliability surface;
- production-readiness separation;
- self-dogfood opportunity/revenue workflows.

## Uneven / unproven
Automation maturity differs by watchdog family. Completeness is not established. Real-world action/value evidence remains limited and must be measured rather than inferred.

## Next proof
Run three golden cases repeatedly with freshness checks and outcome logging. Track source correctness, deadline correctness, false relevance, already-known rate, would-have-missed rate, action-triggered rate and user usefulness.

## Rule
Repository logs, source records and registry state are the truth for what is automated versus curated.
