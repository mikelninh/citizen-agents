# Citizen Agents — Architecture

## System shape
`public sources → watchdogs → source-backed signals → Impact Graph → action/usefulness layer → proof report / API`

## Current surfaces
- watchdog registry;
- curated/automated signal stores;
- Civic Intelligence API;
- Democracy Radar API;
- organisation Impact Graph;
- alerts and reliability surface;
- Founder Control Center / Revenue Opportunity OS;
- production-readiness surface.

## Authority boundary
The intelligence layer may recommend what to review. A consuming organisation/person owns ALLOW / APPROVAL / BLOCK for consequential action.

## Hard-to-reverse choices
Source/provenance model, signal schema, authority semantics, freshness/coverage definitions and public claim rules are RED. Ranking/UI can evolve more freely.
