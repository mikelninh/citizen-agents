# Citizen Agents — Three Golden Cases

## 01 — Rights & Money: “What should I do next?”
A household/person has a concrete situation and a relevant entitlement/rule changes.

Pass only if the answer is source-backed, states important assumptions/unknowns, gives a concrete next action and does not overstate eligibility certainty.

## 02 — Deadline / democracy action window
A public consultation, petition, hearing, election or submission window changes/approaches.

Pass only if the source, deadline, affected audience and remaining action are correct and stale windows cannot remain promoted as actionable.

## 03 — Organisation opportunity / funding signal
An organisation profile is matched to a funding/policy opportunity.

Pass only if the match explains why, preserves eligibility uncertainty, records whether it was already known/missed/actioned and does not turn the programme budget into claimed ROI.
